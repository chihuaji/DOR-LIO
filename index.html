Abstract

Robust state estimation and high-fidelity mapping in dynamic environments remain challenging for LiDAR-Inertial Odometry (LIO) due to the violation of the static-world assumption. Moving objects introduce inconsistent observations that degrade pose estimation and contaminate the reconstructed map. Existing dynamic object removal (DOR) approaches are typically implemented as loosely-coupled pre-processing or offline modules, creating a circular dependency between dynamic filtering and pose estimation.

We propose DOR-LIO, a tightly-coupled LiDAR-inertial odometry framework that jointly performs state estimation and online dynamic object removal. Our system maintains a voxel-level dynamic map and assigns dynamic levels through visibility-based reasoning. During state estimation, only static points are used for residual computation in the Iterated Error-State Kalman Filter (IESKF), preventing dynamic outliers from affecting scan-to-map alignment. A unified multi-resolution map supports both efficient nearest-neighbor search and rapid ray-casting within a single data structure.

Experiments on public datasets, customized simulations, and multi-platform real-world deployments demonstrate that DOR-LIO achieves robust localization and produces clean static maps in highly dynamic environments.

Method Overview

🧮

Tightly-Coupled DOR

Dynamic probability weighting is integrated directly into the IESKF — only voxels with the lowest dynamic level contribute residuals, so moving outliers never corrupt scan-to-map alignment.

🗂️

Unified Multi-Resolution Map

One sparse voxel structure serves both O(1)-style nearest-neighbor search for IESKF updates and conservative ray-casting for visibility-based dynamic reasoning — no disjoint map/localization modules.

🚶

Four-Level Dynamic Reasoning

Voxels carry ordered levels static < aggressive < moderate < dynamic, with spatial dilation near motion boundaries that separates moving structures from genuine static geometry.

🧹

Online Map Clearing

Temporarily static objects that later vacate the scene generate incremental FreeSpace that targets ghost subvoxels for removal — even mistakes made during initialization are corrected online.
