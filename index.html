Key Contributions

Dynamic removal and state estimation, in one iterative pipeline.

01
CORE CONTRIBUTION

Iteratively coupled dynamic removal

Each IESKF iteration refreshes visibility, static-point selection and geometric correspondences.

02

A unified multi-resolution map

One hierarchical map supports nearest-neighbor search and conservative ray casting.

03

Update once, after convergence

Keep the map read-only during estimation, then clear contradicted points and integrate static structure.
